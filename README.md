# 🛒 E-Commerce Website

A modern E-Commerce web application built using HTML, CSS, Bootstrap, and JavaScript.

---

## 🚀 Features

- 🔐 Login Page
- 🛍 Product Listing using API
- ➕ Add to Cart
- 🛒 Cart Page
- ❌ Remove Items from Cart
- 💾 LocalStorage Integration
- 📱 Responsive UI Design
- ⚡ Dynamic Product Rendering

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Fetch API
- LocalStorage

---
